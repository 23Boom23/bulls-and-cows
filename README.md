# Bulls and Cows

A browser game built with TypeScript and functional game logic.

```sh
npm ci
npm test
npm run lint
npm run build
```

Serve the project directory with a local HTTP server after building, for example `python3 -m http.server`, and open `http://localhost:8000`. The build emits ES modules into `dist/`. See [DESIGN.md](DESIGN.md) for the data model, algorithms and complexity.
